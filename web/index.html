Instrucciones del juego
  • Vida: el daño que aguanta un personaje o el boss.
  • Ataque: el daño que hace cada golpe.
  • Velocidad: la probabilidad de atacar dos veces en un turno. Se calcula con el valor más alto entre el personaje y el boss.
  • Esquiva: la probabilidad de evitar un ataque. Se calcula con el valor más alto entre el personaje y el boss.
  • Si respondes bien, atacas al boss. Si respondes mal, el boss te ataca.
  • Al vencer a un boss aparece otro de un nivel más, con mejores stats. Llega al boss de nivel 25 para ganar (35 con un personaje secreto).
  • Al subir de nivel ganas 2 puntos (4 con un personaje secreto) para repartir entre tus stats. Subir la vida también te cura.
  • Las divisiones se responden solo con la parte entera del resultado.
  • Puedes responder con el ratón o con las teclas 1 a 4.
